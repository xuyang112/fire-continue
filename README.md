# fire-continue
# 抖音火花自动续聊工具设计

## 目标

开发一个运行在 Windows 上的本机工具。用户登录 Windows 后，工具自动打开一个专用 Microsoft Edge 窗口，进入抖音网页版，依次向固定好友发送“。”，减少因忘记聊天而中断火花的情况。

第一版仅服务单个本机用户，不提供云端账号、多用户系统或复杂图形界面。

## 使用边界

- 使用抖音网页版已有的聊天能力，不调用未公开接口。
- 使用独立的 Edge 用户数据目录保存抖音登录状态，不读取或干扰用户日常 Edge 配置。
- 不绕过验证码、登录验证或平台风控。
- 登录失效、身份不明确、页面异常或无法确认发送结果时停止相关操作，避免误发。
- 网页结构变化可能导致自动化失效，需要通过日志和截图诊断并更新定位规则。

## 技术方案

采用 Playwright 控制 Microsoft Edge，并使用持久化、专用的浏览器用户目录。

相比连接日常 Edge，该方案可以隔离标签页、扩展和浏览器配置；相比屏幕坐标点击，它可以根据网页元素和文本定位目标，对窗口尺寸变化更有适应性。

## 组件

### 好友配置

配置文件保存固定好友列表。每个好友至少包含昵称；为减少同名误发，支持补充抖音号或主页链接作为身份校验信息。正式发送前必须获得唯一且可确认的匹配结果。

### 启动入口

工具注册为 Windows 用户登录后的启动任务。登录后延迟 90 秒执行，以等待网络和桌面环境稳定。

### 浏览器控制

工具启动专用 Edge，复用已保存的抖音登录状态，打开抖音消息页面，搜索并进入好友聊天。浏览器窗口在执行期间保持可见，便于用户观察和必要时终止。

### 发送保护

工具在发送前再次核对好友身份，只发送固定文本“。”。每位好友每个自然日最多记录一次成功发送；重启电脑不会向已成功的好友重复发送。

### 状态与日志

本地状态记录日期、好友标识、开始时间、发送结果和错误原因。异常时保存页面截图。状态只记录自动化所需信息，不保存抖音密码。

## 执行流程

1. Windows 用户登录后，启动任务等待 90 秒。
2. 读取好友配置和当天执行状态，过滤已经成功的好友。
3. 如果所有好友当天均已成功，记录结果并退出。
4. 启动带专用用户目录的 Edge 并打开抖音消息页面。
5. 检查抖音登录状态；若登录失效或出现验证码，保存截图并停止本次运行。
6. 对每位待处理好友执行搜索，结合昵称和可选的抖音号或主页信息核对身份。
7. 匹配唯一且确认无误后进入聊天，发送“。”。
8. 检查消息是否出现在当前聊天记录中。确认后写入当天成功状态。
9. 某位好友失败时记录原因并继续处理其他好友。
10. 全部处理完成后关闭专用浏览器窗口并退出。

## 重试与错误处理

- 网络或页面加载等瞬时错误，同一步骤最多重试三次，并在重试间加入短暂等待。
- 登录失效、验证码、好友搜索无结果、多个同名结果、身份校验不通过或发送结果无法确认时不执行进一步点击。
- 当天失败的好友不写入成功状态，可在当天下一次开机时再次尝试。
- 日志应明确区分成功、已跳过、可重试失败和需要用户处理的失败。
- 用户随时关闭专用 Edge 窗口即视为中止本次运行，未确认成功的好友不会被标记为成功。

## 首次设置

1. 初始化专用 Edge 用户目录。
2. 打开抖音网页版，由用户亲自扫码登录；工具不采集账号密码。
3. 用户在配置文件中填写固定好友及可用的身份校验信息。
4. 执行一次预演：逐个定位好友并停在发送动作之前，不发送消息。
5. 用户核对预演结果后，显式启用正式发送和 Windows 开机自启。

## 验收标准

- Windows 重新登录后，工具能够延迟启动并完成发送流程。
- 同一好友在同一自然日内不会因电脑重启而重复发送。
- 多位好友之间相互隔离，单个好友失败不会阻止其他好友执行。
- 登录过期、验证码、同名匹配、身份不明确和页面异常不会导致盲目发送。
- 日志能显示每位好友的成功或失败结果；异常包含可供排查的截图。
- 首次预演不会产生任何消息，只有用户启用正式模式后才允许发送。

## 测试策略

- 单元测试覆盖自然日去重、待处理好友筛选、状态写入、配置校验和错误分类。
- 使用本地模拟网页测试好友唯一匹配、同名拒绝、发送成功确认、登录失效和验证码流程，避免自动化测试向真实账号发消息。
- 对真实抖音页面只进行人工控制的预演和一次受控验收；正式发送前由用户确认目标好友。
- 验收时检查日志、截图、Windows 启动任务和重启后的去重行为。

## 非目标

- 不自动识别所有“火花即将中断”的好友。
- 不批量添加好友，不群发营销内容，不读取完整聊天历史。
- 不绕过平台验证，不承诺规避账号风控。
- 第一版不提供远程控制、云同步或移动端应用。
